# 言語から外した機能を使うサンプル

ここに置いてあるのは、**現行の AIPL には無い機能**を使うサンプルである。
動かないのが正しい。歴史として残す。

## become

`become B();` で受け手のクラスを実行時に差し替える機能。
2026 年に言語から外した。理由は三つ。

1. ABCL/1 に無い（どちらの源流にも由来しない）
2. 型を守る制限を課すと、状態フィールドと分岐で書くのとほぼ同じになる
3. 543 本の実プログラムで一つも使われていなかった
   （使っていたのは become 自身のテストだけ）

機械検証の側でも、受け手のクラスが実行時に変わると
「配送時にメッセージの型が合っている」保証が崩れる
（`no_method_not_understood` が成り立たなくなる）。

正典の記録は `~/aios/abclcp/docs/samples/removed/` にある。

## priority(...)

`class HiWorker priority(high) { ... }` というクラス単位の優先度注釈。
三つの処理系のどれにも文法が無い。Xinu のスケジューリング実験のときに
考えていた記法で、言語には入らなかった。
