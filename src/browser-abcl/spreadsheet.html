AIPL — Web Spreadsheet (Round 3 Phase 4 demo)

A 3×3 cell sheet implemented entirely in AIPL. Each cell is its own actor (T4 ActorPerCell + CA4 HybridSpawn). Cell value changes flow through an IT2 EventBus actor to a View actor, which calls the runtime sheet_cell() primitive to repaint the canvas (R3 LayerComposite: selection → grid → text, in that order). The C3 cell is highlighted as the focus.
