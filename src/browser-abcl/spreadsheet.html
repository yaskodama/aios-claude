AIPL — Web Spreadsheet (Round 5 Phase 5.3: Formula Bar)

Click a cell → its address shows in the bar. Type a value or formula (e.g. 42, A1+B1, SUM(A1,B1,A2,B2)) and press Enter to commit. Formula evaluation runs in a tiny JS interpreter (~80 LOC) since the AIPL Sheet doesn't host a runtime parser yet; the AIPL Cell actor receives the computed value via set_cell and the IT2 EventBus repaints.
