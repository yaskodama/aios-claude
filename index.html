aios-claude — AIPL multi-runtime

AIPL is a small actor language (descended from ABCL/1) ported across five runtimes — OCaml, Python (Py·I), JavaScript (Node & browser), C, and bare-metal Xinu/Raspberry Pi 4 — with a "goal → .aice → .ga.json → .aipl" evolution pipeline on top.

🏠 AICE Portal checking…

One-stop launcher for every local dashboard: Py·I, OCaml, Node, browser, C, the evolution pipeline, the local LLM, and the bare-metal Xinu setup & shell pages. Start / Stop / Open each runtime with a click.

http://127.0.0.1:8888/
Browsers can’t launch local processes themselves — run this command in a terminal from the repo root, then click Open: python3 src/aice_home.py  copied!

Runtimes

  • OCaml — canonical interpreter; aipl2c codegen (SDL / Xinu / Python)
  • Py·I — Python reference + live actor dashboard
  • JS (Node) — AIPL parsed & run in a Node server
  • JS (browser) — same runtime, in-page, no backend
  • C — AIPL → C via aipl2c, linked with abcl_nextgen_runtime
  • Xinu / Pi 4 — bare-metal AArch64; HTTP-driven shell & layout
